var DATA = {"brand":"我的第一份分享","subtitle":"在左边把文字改成你自己的内容","footer":"版权声明：本内容由我整理，转载请注明来源。","accent":"#3e7e74","slides":[{"nav":"封面","kicker":"2026 / 11 / 16","title":"不用 PPT，也能做一份好看的演示","lines":["这是一个用网页做的幻灯片。","按 → 或空格翻页，左边可以点目录直接跳页。"]},{"nav":"今天聊什么","kicker":"Opening","title":"今天分享三件事","lines":["第一件：这份幻灯片是什么。","第二件：它是怎么做出来的。","第三件：你怎么做出自己的一份。"]},{"nav":"怎么做","kicker":"How to","title":"填字 → 下载 → 打开","lines":["左边每一页改标题和正文，右边会实时变。","点「下载我的幻灯片」得到一个 index.html。","双击打开就能播放，不需要联网、不需要装软件。"]},{"nav":"发到网上","kicker":"Share","title":"想让别人也能看？","lines":["把 index.html 传到 GitHub 仓库，开启 Pages。","一分钟左右就会得到一个公开网址。","具体点哪几个按钮，下面折叠说明里写着。"]},{"nav":"结尾","kicker":"The end","title":"谢谢看到这里","lines":["把内容换成你的主题，就是一份新的演示。"]}]};

var root = document.documentElement, W = 1280, H = 720, GAP = 32;

var pad = function(n){ return String(n).padStart(2, '0'); };

document.title = DATA.brand;

document.getElementById('frame').style.setProperty('--accent', DATA.accent);

document.getElementById('brandText').textContent = DATA.brand;

document.getElementById('subText').textContent = DATA.subtitle;

document.getElementById('sign').textContent = DATA.footer;

var stage = document.getElementById('stage'), nav = document.getElementById('nav');

var slides = [], navBtns = [], active = 0;

DATA.slides.forEach(function(s, i){

  var sec = document.createElement('section');

  sec.className = 'slide';

  var inner = document.createElement('div');

  inner.className = 'inner';

  var n = 0;

  if (s.kicker) {

    var k = document.createElement('p');

    k.className = 'kicker animate';

    k.style.setProperty('--i', n++);

    k.textContent = s.kicker;

    inner.appendChild(k);

  }

  var h = document.createElement('h2');

  h.className = 'animate';

  h.style.setProperty('--i', n++);

  h.textContent = s.title;

  inner.appendChild(h);

  (s.lines || []).forEach(function(line){

    if (!line.trim()) return;

    var p = document.createElement('p');

    p.className = 'body animate';

    p.style.setProperty('--i', n++);

    p.textContent = line;

    inner.appendChild(p);

  });

  sec.appendChild(inner);

  stage.insertBefore(sec, stage.firstChild);

  var btn = document.createElement('button');

  btn.type = 'button';

  btn.textContent = pad(i + 1) + '  ' + (s.nav || s.title);

  btn.addEventListener('click', function(){ show(i); });

  nav.appendChild(btn);

  slides.push(sec);

  navBtns.push(btn);

});

document.getElementById('total').textContent = pad(slides.length);

function fit(){

  if (window.matchMedia('(max-width: 980px)').matches) { root.style.setProperty('--scale', 1); return; }

  var s = Math.min(1, (window.innerWidth - GAP) / W, (window.innerHeight - GAP) / H);

  root.style.setProperty('--scale', s);

}

function show(i){

  active = Math.max(0, Math.min(i, slides.length - 1));

  slides.forEach(function(s, n){

    s.classList.toggle('active', n === active);

    if (n === active) {

      s.querySelectorAll('.animate').forEach(function(el){

        el.style.animation = 'none'; void el.offsetWidth; el.style.animation = '';

      });

    }

  });

  navBtns.forEach(function(b, n){ b.classList.toggle('active', n === active); });

  document.getElementById('cur').textContent = pad(active + 1);

  document.getElementById('bar').style.width = ((active + 1) / slides.length * 100) + '%';

}

var next = function(){ show(active + 1); }, prev = function(){ show(active - 1); };

document.getElementById('next').addEventListener('click', next);

document.getElementById('prev').addEventListener('click', prev);

window.addEventListener('keydown', function(e){

  if (['ArrowRight','PageDown',' '].indexOf(e.key) > -1) { e.preventDefault(); next(); }

  if (['ArrowLeft','PageUp'].indexOf(e.key) > -1) { e.preventDefault(); prev(); }

  if (e.key === 'Home') show(0);

  if (e.key === 'End') show(slides.length - 1);

});

window.addEventListener('message', function(e){

  if (typeof e.data === 'number') show(e.data);

});

window.addEventListener('resize', fit);

var q = parseInt(new URLSearchParams(window.location.search).get('slide') || '1', 10);

fit();

show(Number.isFinite(q) ? q - 1 : 0);
